\# VSD BabySoC — RTL to GDSII



This directory contains my BabySoC RTL simulation, logic synthesis, and physical design work completed as part of the VLSI System Design (VSD) workshop.



\## Project Structure



\### 1. BabySoC RTL Logic Synthesis



\*\*Directory:\*\* `BabySoC\_RTL\_Logic\_Synthesis/`



Contains the simulation and synthesis work, including design netlists, simulation waveforms, synthesis statistics, and supporting images.



\[Explore RTL Logic Synthesis](BabySoC\_RTL\_Logic\_Synthesis/README.md)



\### 2. BabySoC Physical Design



\*\*Directory:\*\* `Lab\_PD\_VSDBabySoC/`



Contains the physical design work, implementation reports, floorplan and placement images, clock-tree synthesis results, routing results, and static timing analysis documentation.



\[Explore Physical Design](Lab\_PD\_VSDBabySoC/README.md)



\## Workflow Overview



The project documents the progression from RTL simulation and logic synthesis to physical design implementation and timing analysis.



\- RTL simulation and verification

\- Logic synthesis and netlist inspection

\- Floorplanning and placement

\- Clock-tree synthesis

\- Routing and implementation analysis

\- Static timing analysis across PVT corners
